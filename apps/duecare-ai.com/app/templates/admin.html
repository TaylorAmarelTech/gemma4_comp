Token-gated troubleshooting

Admin logs for the hub without exposing raw case data.

Use this page during rehearsals, deploys, and partner demos to see storage health, latest accepted signals, update proposals, automation verdicts, and local-KB counts. The API is disabled unless DUECARE_ADMIN_TOKEN is configured, and every returned record is redacted before display.

Connect to the admin API

Paste the deployment token for this browser session. It is stored only in localStorage and sent as X-DueCare-Admin-Token.

If the deployment does not set a token, the API returns 403 by design. The public site never exposes these logs anonymously.
