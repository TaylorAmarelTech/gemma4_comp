Local install

shell · macOS / Linux 
# pull and verify the latest vetted runtime
curl -fsSL https://duecare-ai.com/install.sh | sh

# pull the corridor pack you need (signed; verifies checksum)
duecare packs pull "corridor/qa-np@latest"
duecare packs verify "corridor/qa-np"

# run the local harness; no network required after pull
duecare harness run --offline --pack corridor/qa-np

Pull the contact & tools packs

shell
duecare packs pull "contacts/qa-np"
duecare packs pull "tools/complaint-draft@1.4"
duecare packs pull "grep-rules/recruitment@stable"
Hard contract

What leaves vs. what stays local

  • Stays local: case content, names, contacts, messages, decisions.
  • May cross (anonymized, k≥30, opt-in): anonymized pattern_id, corridor, sector.
  • Hub never accepts: raw text fields. Schema rejects them at the edge.
