26-kernel roster

The full kernel index.

DueCare ships 26 Kaggle script kernels: 3 core entry points, 11 reproducible-pipeline appendix slots, 9 website-aligned extensions, and 3 Gemma 4 feature showcases. Every kernel has a folder under kaggle/ with kernel.py, a README.md with a Judge-quick-path table, and a kernel-metadata.json for the Kaggle CLI. Source on GitHub; canonical index at kaggle/_INDEX.md.

Roster invariants (all 26 kernels)

  • Every kernel folder has a kernel.py, a README.md with a "Judge quick path" table (Inputs / Gemma 4 features / Outputs rows), and a kernel-metadata.json for the Kaggle CLI.
  • Every JSON-emitting kernel produces a v1.0 BundleEnvelope per docs/data_primitives.md — schema_version + kernel_id + run_id + summary + results[].
  • Four kernels (A-19, A-21, A-22, A-23) are reference implementations of duecare.appendix_primitives.write_v1_bundle(); the helper module ships in duecare-llm-chat v0.17.0+.
  • Seven kernels (03, A-18a, A-19, A-20, A-21, A-22, A-23) are zero-inference cached patterns — recording-friendly, no GPU required.
  • Static audit gate at scripts/validate_public_surface.py runs six checks (drift terms, route 200 sweep, five-lane order, kaggle lane labels, bundle envelope v1, manifest checksums) on every PR. Currently 0 findings.
