The Problem

A 23-year-old Filipina domestic worker paid PHP 50,000 in “training fees” before her Hong Kong visa was released.

Philippine law says that fee is illegal. She didn't know. She paid.

Composite scenario. Built from published ILO indicators and POEA enforcement cases. Names and case numbers are synthetic.

Why this is the right problem

The fee is one signal. Pulled together, they tell the trafficking story.

illegal recruitment fees collected from Filipino OFWs each year (POEA enforcement reports)

A worker with a phone, an NGO caseworker, or a regulator should be able to spot these patterns in seconds — without exporting case details to a frontier API.

The Solution

DueCare wraps Gemma 4 with a harness ecosystem that runs entirely on-device.

Gemma 4 is the engine. The harness ecosystem is what makes it trustworthy:

  • GREP rules — >100 deterministic patterns for recruitment-fee, contract, passport, retaliation signals
  • RAG corpus — ILO conventions, POEA circulars, HK Labour Department citations
  • Deterministic tools — corridor fee-cap lookups, NGO contacts, ILO indicator matcher
  • Privacy gates — anonymization + search-safety + post-search verification
  • Combined rule + LLM judge — neither alone, but both, with normalized scoring

Audiences:

  • Migrant workers — phone-based safety check
  • NGO caseworkers — bulk case review
  • Regulators — pattern + corridor evidence
  • Researchers — reproducible benchmarks
  • Platform safety teams — moderation API
Live demo · Worker-facing chat

The worker asks. The harness answers with cited evidence.

Audience: worker · Use case: PH-HK placement fee cached
A recruiter says I have to pay PHP 50,000 in training fees before my Hong Kong visa will be released. Is this legal?
Gemma 4 + DueCare harness · combined rule + LLM judge
No. For Filipino domestic workers bound for Hong Kong, the worker-paid placement fee is zero PHP under POEA MC 14-2017 (the implementing rule for the Migrant Workers and Overseas Filipinos Act, RA 8042). Charging training, processing, medical, or transport fees against the worker is the same prohibited conduct under a different label — the substance is what matters, not the wording on the receipt. Specific things you can do right now: - Ask the recruiter for a written breakdown of every fee, in Philippine pesos, with the recipient name and account number. - Photograph any receipt or contract before signing. - Call the DMW Anti-Illegal Recruitment Branch hotline before paying (verify the current number via the DueCare contacts pack). - Mission for Migrant Workers in Hong Kong is a vetted referral if you arrive and the situation continues. This response was produced locally on Kaggle T4 hardware. No raw case detail left the kernel.

Live demo · NGO caseworker · Bulk File Review

Upload a case bundle. Get a typed evidence graph in seconds.

The Bulk File Review surface processes a five-document PH-HK case bundle (chat, contract, payment ledger, complaint, manifest) and emits 42 typed edges:

  • fee_amount_observed × 6 — recruitment-fee proxies
  • salary_deduction_signal × 5 — wage-deduction proxies
  • journey_stage_observation × 9 — recruitment / signing / deployment / complaint
  • dated_evidence × 11 — anchor each signal to a date
  • located_at × 5 — geography of the case
  • filed_under × 6 — folder structure as evidence

Ask the graph: “Which rows support fee camouflage and restricted provider choice?” — the deterministic branch surfaces both signal families with cited row IDs. No model required.

analysis_kind: fee_camouflage_and_provider_choice Fee camouflage candidates - recruiter_chat.txt edge: fee_amount_observed label: PHP 45,000 placement loan - payment_ledger.csv edge: salary_deduction_signal label: monthly deduction Restricted provider choice candidates - manifest.json edge: journey_stage_observation label: recruitment Run the optional local Gemma edge pass to upgrade these proxies into explicit fee_camouflage_evidence and provider_choice_restriction edges.
