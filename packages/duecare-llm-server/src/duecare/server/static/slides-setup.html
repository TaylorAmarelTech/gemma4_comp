How to use this

  1. Pick the audience and use case for one slide. Click Generate.
  2. Review the prompt and response. Re-generate if you want a different framing.
  3. Click Save for slides. The row is stored in localStorage['duecare.slides.demo.chat'].
  4. Open Project slides — demo chat slide. The cached row appears automatically.
  5. Record. The slide deck never blocks on live inference.
