How to use this

  1. Fast path: click Preload recording pack. This stores selected examples in localStorage['duecare.slides.demo.pack'] and the chat-slide row in localStorage['duecare.slides.demo.chat'].
  2. Manual path: pick the audience and use case for one slide, then click Generate.
  3. Review the prompt and response. Re-generate if you want a different framing.
  4. Click Save for slides if you generated one manual row.
  5. Open Project slides — demo chat slide. The cached row appears automatically.
  6. Record. The slide deck never blocks on live inference.
