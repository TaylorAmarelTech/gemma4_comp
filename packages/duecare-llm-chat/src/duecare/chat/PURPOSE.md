# Chat - purpose

**Module id:** `duecare.chat`

## One-line

DueCare reviewer workbench and Gemma 4 harness app.

## Long-form

`duecare.chat` serves the FastAPI app, static workbench pages, shared
model-loading chrome, harness contracts, and local Gemma 4 integration
used by the Kaggle workbench kernels. It includes chat, comparison,
Bulk File Review, Knowledge Extraction, Search, Templates,
Anonymization & Sharing, sync/status utilities, replay artifacts, and
sample-bundle flows.
