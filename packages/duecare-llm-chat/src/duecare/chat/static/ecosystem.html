Deployment Modes

The same harness contracts support three operational shapes. Judges can test the local Kaggle instance today, while partners can map the same contracts into tenant-owned moderation queues or a privacy-preserving knowledge network.

ModePrimary UsersWhat Runs LocallyWhat Can Touch The Network
Local instance Worker, caseworker, researcher, judge Gemma 4, harness layers, imported evidence, grading, and graph extraction. Only optional search and optional pack sync. Raw case files stay in the kernel or device.
Enterprise or on-prem screening Platform safety, regulator, NGO office, integration partner Moderation API, batch review queue, tenant packs, audit logs, local graph, and reviewer UI. Optional anonymized pattern signals and vetted pack pulls. The enterprise review pipeline decides actions.
Networked knowledge hub Civil-society curators, researchers, partner deployments Local anonymization, consent labels, hash receipts, and proposal preview. Public-source facts, anonymized signals, vetted/unvetted pack metadata, and curator-approved updates.
raw cases stay local hub stores sanitized objects civil society vets updates clients pull versioned packs
