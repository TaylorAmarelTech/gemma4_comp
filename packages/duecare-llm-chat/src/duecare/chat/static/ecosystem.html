Local Node Intelligence Network

DueCare is strongest as an ecosystem of many local nodes: a worker device, NGO office, regulator queue, platform safety team, researcher, or developer integration can all run the same privacy-first process. Gemma 4 helps each node convert messy local evidence into reviewable hierarchy-level facts before anything leaves the node.

Deployment Modes

The same harness contracts support three operational shapes. Judges can test the local Kaggle instance today, while partners can map the same contracts into tenant-owned moderation queues or a privacy-preserving network of nodes that share reviewed anonymized intelligence.

ModePrimary UsersWhat Runs LocallyWhat Can Touch The Network
Local instance Worker, caseworker, researcher, judge Gemma 4, harness layers, imported evidence, grading, and graph extraction. Only optional search and optional pack sync. Raw case files stay in the kernel or device.
Enterprise or on-prem screening Platform safety, regulator, NGO office, integration partner Moderation API, batch review queue, tenant packs, audit logs, local graph, and reviewer UI. Optional anonymized fact objects, pattern signals, and vetted pack pulls. The enterprise review pipeline decides actions.
Networked knowledge hub Civil-society curators, researchers, partner deployments Local anonymization, consent labels, hash receipts, and proposal preview. Public-source facts, anonymized evidence edges, vetted/unvetted pack metadata, and curator-approved updates.
raw cases stay local hub stores sanitized objects civil society vets updates clients pull versioned packs
