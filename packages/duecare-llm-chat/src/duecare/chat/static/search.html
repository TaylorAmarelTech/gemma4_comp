Search and Source Intake

Calls POST /api/search/client. This is a secondary utility surface, not a Gemma response harness by itself. Uses SearXNG when configured (privacy-preserving meta-search), falls back to the kernel's wired Tavily/Brave/DDG. Search Safety strips PII before the query reaches any backend. After results arrive, use the result cards to draft knowledge envelopes from each snippet or download the result set as JSON or markdown.

What this workflow does

Search is the public-source intake path. Sanitize a query, retrieve sources, review result cards, then draft useful results into knowledge objects that can be saved locally and later exported or shared through the dedicated knowledge and anonymization flows.
