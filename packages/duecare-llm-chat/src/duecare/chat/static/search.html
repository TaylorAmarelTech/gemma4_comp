Calls POST /api/search/client. This is a secondary utility surface, not a Gemma response harness by itself. Uses SearXNG when configured (privacy-preserving meta-search), falls back to the kernel's wired Tavily/Brave/DDG. Search Safety strips PII before the query reaches any backend. After results arrive, the local post-search verification gate scores source quality, relevance, and deanonymization risk before a result can be drafted into knowledge.

What this workflow does

Search is the public-source intake path. Sanitize a query, retrieve sources, review result cards, then draft useful results into knowledge objects that can be saved locally and later exported or shared through the dedicated knowledge and anonymization flows.

Safety firstPII is stripped before any third-party backend sees the query.
Source reviewEach result stays inspectable as a source card before it becomes knowledge.
Knowledge pathDrafts go through the same Knowledge Extraction envelope flow used elsewhere.
Ecosystem inputReviewed public-source facts can update local packs or become safe proposals for shared intelligence.
Gemma 4 roleGemma 4 rephrases the redacted query for stronger generalization, then optionally drafts envelopes from each result. Without a loaded model the deterministic path still works end-to-end.

How saving works and model-fit guidance (click to expand)

Each search result was passed to /api/knowledge/draft-envelope with target_leaf=auto, use_gemma=false, and the kernel's Anonymizer applied first. This keeps public-source intake fast and avoids long tunnel waits. Open Knowledge Extraction for deeper Gemma refinement of any saved source. Review each draft, then click Save all to local knowledge store to persist them via /api/knowledge/promote, or download as a single JSON for offline review.

Model fit: small Gemma models are useful for later rephrasing or compact refinement, but search-result snippets should still be checked against the opened source before promotion. Current phone numbers, statutes, and enforcement facts should remain reviewable knowledge, not hardcoded text.
