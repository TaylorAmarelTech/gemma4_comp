Search Utility

Calls POST /api/search/client. This is a secondary utility surface, not a Gemma response harness by itself. Uses SearXNG when configured (privacy-preserving meta-search), falls back to the kernel's wired Tavily/Brave/DDG. Search Safety strips PII before the query reaches any backend. After results arrive, use the action buttons below the results to draft knowledge envelopes from each snippet, download the result set as JSON or markdown, or send the set into Anonymization & Sharing for hub upload.
