Persona …
Expert anti-trafficking persona prepended to every message. Gives Gemma the role + framework + tactics knowledge.
▸ View & Configure
GREP …
Regex KB rules — trafficking patterns, ILO indicators, statute matches. Prepended to Gemma's context with citations.
▸ View & Configure
RAG …
BM25 lexical retrieval (~1ms, no embeddings) over an in-kernel corpus of ILO conventions, POEA/BP2MI circulars, HK statutes, NGO briefs. Top-5 docs injected as Gemma context. Deterministic + GPU-free by design — see ▸ View & Configure for the rationale + corpus list.
▸ View & Configure
Tools …
Heuristic lookup tools — corridor fee caps, fee camouflage decoder, ILO indicator matcher, NGO intake hotlines. Results injected as Gemma context.
▸ View & Configure
Online …
Live web search — Tavily / Brave (BYOK) or kernel DuckDuckGo. Optional deep-fetch mode downloads the top-N URLs, converts HTML→markdown, runs GREP rules over each page, and prepends the parsed bodies + hits as Gemma context. Cross-check required for any cited claim.
▸ View & Configure
Import …
Internal-intelligence corpus — paste your own documents (statutes, NGO briefs, case files) and Gemma will ground its answer in them. Stays in your browser; never leaves the session.
▸ View & Configure
