Use Case 05 | Developer / integration partner

Drop the runtime into your own product or channel.

A containerized runtime with a small, well-defined API can be wired into a Messenger or WhatsApp bot, a moderator console, an internal case-management system, or a sibling app. You own the channel. DueCare provides the harness, the rule packs, and the Gemma 4 model layer.

Inspect Harness Contracts Open /api/version

Deployment modes

Local runtime
Run the workbench or API on a laptop, Kaggle kernel, office server, or mobile-adjacent device. Raw content stays local.
Enterprise screening
Wire the API into a moderation queue or case system. DueCare flags and explains; your existing reviewer workflow acts.
Networked hub
Submit only anonymized pattern objects, pull vetted packs, and keep volatile contacts and policy facts out of model memory.
