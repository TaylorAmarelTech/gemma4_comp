Model loading mode

Loading a Gemma 4 fine-tune takes time (E4B around 30s, larger variants 1-3 min). Loading two simultaneously can OOM on a single T4 or trigger expensive cold-starts. The kernel's default behaviour is single-model: when a new model is requested, the previously loaded one is unloaded first.

If your environment has enough VRAM (single A100, dual T4, or larger), you can opt into multi-model mode to keep loaded models resident for instant comparison without the reload penalty. Setting is per-device, stored in localStorage.

checking...

Caveats: multi mode does NOT increase your GPU's capacity. If you load several large variants it will OOM. The kernel will refuse a second concurrent load if free VRAM is below a safety margin. Switch to single if you see OOMs or slow swaps. The activity log on the Models page records every load/unload with timing.
