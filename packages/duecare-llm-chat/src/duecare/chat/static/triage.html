Platform Triage

Screen a batch of job ads or recruiter messages through the waterfall: deterministic GREP rules, a fast-model verdict, deep grounded Gemma 4 only for the risky few. The platform-safety lane, live.
Trust boundary: pasted items go only to this kernel's POST /api/triage/screen. The GREP and deep tiers always run locally; the fast tier runs on the loaded local Gemma unless the operator has pointed DUECARE_FAST_MODEL_BASE_URL at an endpoint they control (a DiffusionGemma-class model served via vLLM — see the tier card below for what is active right now). Responses and the training log carry counts and sha256 hashes only; raw item text is never echoed back or persisted. Fast-tier verdicts only route items — they are never user-facing answers.
