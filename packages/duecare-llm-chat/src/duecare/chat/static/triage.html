Platform Triage

Screen a batch of job ads or recruiter messages: deterministic GREP rules flag known patterns, then the one loaded Gemma 4 — the same model the chat page uses — gives a flag/clear verdict on the rest. The platform-safety lane, live.
Trust boundary: pasted items go only to this kernel's POST /api/triage/screen and are screened entirely on the already-loaded local Gemma — no second model, no external endpoint, no model switch. Responses and the training log carry counts and sha256 hashes only; raw item text is never echoed back or persisted. The model verdict only routes items — it is never a user-facing answer.
