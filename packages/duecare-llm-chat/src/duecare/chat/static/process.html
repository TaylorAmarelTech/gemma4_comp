Step 2 -- What the kernel will do

  1. Unpack + validate -- ZIPs are unpacked in /kaggle/working/process-staging/; each contained file becomes one row.
  2. Harness pass -- each row goes through Persona + GREP (161 rules) + RAG (46-doc corpus) + Tools (5 lookups).
  3. Entity recognition -- extract PERSON / EMPLOYER / RECRUITER / AMOUNT / CORRIDOR / STATUTE per row.
  4. Gemma-guided pass -- the loaded model writes a 5-sentence narrative summary and labels each sentence with its source row_id.
  5. Bundle emit -- canonical v1.0 envelope (<RUN_ID>_process_bundle.zip) for downstream tabs.
