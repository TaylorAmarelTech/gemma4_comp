Bulk File Review

Trust boundary: Uploaded rows are processed locally in the kernel (/kaggle/working/process-staging/). The harness runs in-process; no row is sent to any remote service. Outputs stay in the kernel until you explicitly Anonymize + Submit.

Drop a ZIP, CSV, JSONL, PDF, image, or text bundle of case material: chat exports, scans, recruitment ads, court excerpts, recorded testimony transcripts, and document photos. Each row goes through the process harness: GREP, entity extraction, document typing, person linking, hierarchy construction, and a compact Gemma 4 case-brief pass when a model is loaded. The page renders the extracted intelligence so you can inspect the graph before asking Gemma 4 questions about it.
