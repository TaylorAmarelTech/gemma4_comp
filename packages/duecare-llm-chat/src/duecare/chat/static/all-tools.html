All workbench tools

Every capability, on its own page.

The DueCare Workbench surfaces every API capability of the chat package as a focused page. Audience showcases (Platform safety, NGO & regulator, Worker, Researcher, Developer) curate these tools into role-specific demo flows. This index is the flat list.

Chat & classification

Chat playground
Free-form Gemma chat with the full harness — every layer, every grading mode, every model variant.
Content classifier
Score a single piece of content (text or image) → recommended action + per-rule explanation.
Grade a response
Paste prompt + response → 3-mode grade panel (rule-based / LLM-judge / combined). Current rubric with 0-10 per-dimension scorecards.

Layer transparency

Layer catalog
6-card index of persona / GREP / RAG / tools / online / import. Live counts from /api/brand.
Persona library
System prompts that shape Gemma's response stance per audience.
All GREP rules
Sortable table with severity, citations, fire counts, category histogram.
Live GREP tester
Paste any text — see which rules fire (no LLM, ~5ms).
RAG corpus
Browse ILO / POEA / BP2MI / HK / Saudi / UAE legal documents grouped by jurisdiction.
Citation graph
Force-directed view of the bundled corpus and cross-citations between sources.
Function-calling tools
5 tools + corridor fee caps + camouflage labels + ILO indicators + NGO groups.
Online search providers
Brave / Tavily / DDG backend config + BYOK key wiring.
Cross-layer search
One query searches across persona, GREP, RAG, and tools simultaneously.

Worker / NGO utilities

Hotlines directory
Versioned contact pack for NGOs, regulators, embassies, and ILO offices, with verification metadata.
Anonymization preview
See what would be sent to the public hub before submitting any case data.
Knowledge import
Drag-drop documents (.txt/.md/.json/.csv/.pdf/.zip) into the in-kernel BM25 retrieval pool. List + delete imported docs. Never leaves the kernel.

System & observability

Models
All 9 Gemma 4 variants, the currently-loaded model, GPU memory, live load-phase logs. Load any variant without restarting the kernel.
Logs & audit trail
Standardized JSON-Lines events from every kernel — filter by level / kind prefix / layer. Auto-refreshes every 2 seconds.
Settings
Retrieval config (BM25/dense/RRF + parent-expand + embed-cache reset) and online search backend (Brave/Tavily/DDG/Wikipedia + BYOK keys + live test).
Raw /api/version
Direct JSON: package version + per-layer counts.
