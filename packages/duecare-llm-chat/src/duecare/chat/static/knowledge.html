Knowledge Extraction -- paste text, Gemma 4 drafts a standardized knowledge module

Trust boundary: Extraction runs locally against the loaded Gemma 4 model. Drafted envelopes stay in /kaggle/working/knowledge/; nothing leaves the kernel unless you anonymize and submit on Anonymization & Sharing.

Paste raw text (a recruiter message, a court filing, an NGO field note). Gemma 4 + the extraction prompts draft a candidate envelope (grep_rule, glossary_term, statute_citation, indicator, fact_template). Review the draft, optionally anonymize, then promote it -- or jump to Anonymization & Sharing to submit the lot to the public hub.

Try the sample envelopes (round-trip the import flow)

Two pre-built artefacts let you confirm the import path works end-to-end. The single envelope is a plain JSON file you can open in a text editor; the bundle is a ZIP of four envelopes (grep_rule + rag_doc + context_snippet + rubric_dimension) pathed as <type>/<id>.json so /api/knowledge/import accepts it directly.

1. Paste raw text

Gemma 4 will infer the regex / citation / definition that best captures this passage. Examples: a recruiter clause hiding a placement fee, a statute citation, a sector-specific term.

One leaf per draft: Gemma drafts a SINGLE envelope of the selected type each time you click Extract. The selector controls what shape Gemma produces (regex vs. definition vs. citation etc.); the page itself does not generate all five at once because each leaf type has a distinct schema and prompt. To draft several leaves from the same passage, change the selector and click Extract again -- each draft is saved separately. For batch generation across all 21 leaves of the taxonomy, use the manual authoring section below or the workflows under Layers.
