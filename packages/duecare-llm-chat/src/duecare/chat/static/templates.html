Templates

LOCAL BUNDLE-DRIVEN REVIEWER GATED Templates render locally from the case bundle currently held in memory. Gemma 4 fills gaps when loaded; the caseworker always has the final edit before download.

Turn a processed case bundle into a draft complaint or referral document. Pick a template, attach the latest bundle from Bulk File Review (or paste structured intelligence as JSON), let Gemma 4 propose field values, then edit and export. Templates ship with HK Labour Department, POEA/DMW, IOM, and a generic NGO intake form; each is a Jinja-style placeholder document with no HTML.

Where Gemma 4 runs on this page:
  1. Deterministic field hints (no Gemma) — the bundle's intelligence (people, employers, payments, journey points) is mapped directly to fields where a source_hint is declared. Green border = filled from the bundle.
  2. Gemma 4 fills the gaps — when "Use Gemma 4 to fill" is checked and a model is loaded, Gemma proposes values for the remaining required fields. Teal border = Gemma proposed. Output is strict JSON; the renderer rejects any field Gemma fabricated outside the template's schema.
  3. Caseworker authority — manual edits override everything. Amber border = manually overridden. The "missing" tag is honest: Gemma did not have enough evidence and you have not entered the value yet.
Names are anonymized to first-initials in proposed values. Names you type manually are preserved as written.
