What gets shared, when you click "Send"

DueCare runs a local anonymization pipeline before any text crosses to the public hub. This page lets you preview the exact payload. Nothing is sent until you choose to send it.

How the boundary is enforced

  • Stage 02 (regex) runs in the browser. Email, phone, identity-document, and street-address patterns are replaced with typed placeholders before any network call.
  • Stage 03 (server automation) re-runs the same checks plus an LLM-based content-safety + PII pass. If anything slipped through Stage 02, the server rejects with a 422.
  • Curator review is the third gate. The hub never auto-publishes. Every vetted pack carries a curator signature.
  • Retract. If a curator hasn't reviewed yet, you can call POST /api/hub/client/submission/retract with the submission id and it disappears from the queue.
