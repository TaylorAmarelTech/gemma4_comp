Use Case 03 | Individual worker / mobile

Plain-language answers about a corridor.

Migrant workers and partner-hosted channels can use DueCare to ask about fees, contracts, passports, and rights in their own language. The system does not file complaints or instruct risky action. It points to verified resources and trusted caseworkers.

Privacy boundary: messages typed here stay on the kernel running this URL. Nothing is sent to the public hub unless you explicitly use an anonymization and sharing flow.
