Trust boundary: This status page reads provider configuration from the local kernel only (/api/harness-catalog/online). No case data or search queries are sent to external services by this page. Brave Search and DuckDuckGo are only contacted during an active chat session when the Online toggle is ON in the chat harness. To override the active provider, set BRAVE_API_KEY in the kernel environment.

Live web-search providers

The Online layer prepends a cross-check warning to every result the Gemma context receives, so the model treats them as candidate evidence requiring URL attribution rather than ground truth. Deep-fetch (httpx) pulls the linked page so the model sees real content, not just snippets. Appendix A9 (duecare-chat-playground-with-agentic-research) replaces the single-shot search with a multi-step Playwright-driven loop.

How the Online layer is wired in the harness

When the Online toggle is ON, the kernel passes online_search_call=... into create_app(). This callable receives the user prompt and a budget, returns a list of result objects with url, title, snippet, and (deep-fetch ON) full text. The chat-package wraps each result with the cross-check warning before prepending to the Gemma context.

The pipeline modal's per-layer card shows: provider used, query terms, result count, deep-fetch URLs, and total bytes added to the prompt.
