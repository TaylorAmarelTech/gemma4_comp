Models

The 9 Gemma 4 variants the workbench can load, the currently-resident model, and the live load-phase log stream. This page delegates model selection and loading to the same universal top-bar model service used by Chat, Compare, Bulk Review, Knowledge Extraction, Search, and Sharing.

Model load path

1 Choose one model for the session Kaggle is most reliable when one Gemma variant is resident at a time.
Use Settings only if you intentionally want multi-model hot loading on a high VRAM machine.
2 Wait for load logs The loader streams progress and exposes errors without leaving the page.
The top chrome model selector is the only load service. This page is a readout plus shortcut buttons into that service.
3 Use the loaded model everywhere Chat, comparison, grading, extraction, and process graph chat all read the same kernel model.
This keeps the live demo aligned with Kaggle's practical one-model session constraint.
