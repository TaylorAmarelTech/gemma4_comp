Same prompt, two harness configurations. Send one prompt through both and see what each safety layer changes. Variant A is typically stock Gemma 4 (no layers); Variant B is the full local DueCare harness by default. Run order: both variants share the single loaded Gemma 4, so they execute sequentially (A first, then B). The safety layers (Persona, GREP, RAG, Tools, Official Sources, Online) fire per variant before each model call. Every step streams into the activity log at the bottom of the page in real time. 6. Grade both responses

Score each variant on the same rubric. Mode determines which grader runs: deterministic = rules-based (/api/grade); deep = Gemma-as-judge (/api/grade-deep, slower); combined = weighted blend.

Judge model · using chat model (default) Suggested

By default the chat model also grades. For higher accuracy on the LLM-judge passes (deep and combined modes), load a larger model into the dedicated judge slot. The chat model stays loaded so A/B inference isn't disrupted; both models can stay resident if VRAM allows. Recommended: Gemma 4 31B-it.
