Harness Comparison

Same prompt, two harness configurations. Send one prompt through both and see what each safety layer changes. Variant A is typically stock Gemma 4 (no layers); Variant B is the full DueCare harness. Run order: both variants share the single loaded Gemma 4, so they execute sequentially (A first, then B). The safety layers (Persona, GREP, RAG, Tools, Online) fire per variant before each model call. Every step streams into the activity log at the bottom of the page in real time. Use the top Model control to load or switch the active model for all workbench pages.
