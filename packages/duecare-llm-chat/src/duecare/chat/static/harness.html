Duecare — Harness inspector

Browse every component of the safety harness. Each card is a dedicated viewer.
Direct API endpoints — call from the Kaggle kernel or curl:
  • GET /api/version — chat-package + rubric version + per-layer counts
  • GET /api/health-check — wired layers + model info
  • GET /api/harness-catalog/{persona|grep|rag|tools|online} — raw catalog JSON
  • GET /api/rag/graph — corpus + 46-edge citation graph (force-directed view)
  • GET /api/governance — list of curator-block JSON files
  • GET /api/governance/<name> — raw curator JSON for a single block
