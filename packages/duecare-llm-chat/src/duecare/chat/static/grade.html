Grade a response

Paste a prompt + an assistant response. The current universal rubric scores each applicable dimension from 0 to 10 (citation, refusal, contacts, privacy, actionability, grounding) and produces a final verdict. The LLM-judge variant sends each yes/no dimension question back to the loaded Gemma model; Combined blends the two with a disagreement panel.

Grading path

1 Paste a complete exchange The prompt determines which dimensions are applicable. The response determines scoring.
This keeps N/A driven by the scenario instead of rewarding responses that avoid important content.
2 Pick the judge Rule-based is fast. LLM judge checks harder dimensions. Combined exposes disagreement.
Use combined mode for demo evidence and regression review. Use rule mode for quick bulk checks.
3 Inspect evidence Scores, rationales, and disagreement details reveal what the harness or model needs to improve.
Dimensions around authoritative contacts, regulator contacts, retaliation risk, citation grounding, and refusal quality are surfaced when relevant.
