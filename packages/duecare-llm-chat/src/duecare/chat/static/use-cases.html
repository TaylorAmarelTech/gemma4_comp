Workbench use cases

Five ways to test DueCare with Gemma 4.

These are the same audience lanes used in the public project story and video pitch. Each page gives sample prompts, the expected harness path, and links into the working UI so judges can test the actual runtime.

Audience lanes

01 Platform safety
Screen exploitative user-generated recruitment content at scale.
02 For NGOs & regulators
Speed up case intake, triage, complaint drafts, and evidence review.
03 Individual worker / mobile
Plain-language corridor answers while keeping sensitive facts local.
04 Researcher
Version-pinned packs, reproducible runs, and citeable model behavior.
05 Developer / integration partner
Embed the runtime into bots, moderator consoles, case systems, or on-prem deployments.

Quantitative proof path

A/B Harness Comparison
Run one prompt through no-harness and harnessed configurations, then grade both.
Bulk File Review
Process the PH to HK synthetic case bundle and inspect the extracted graph.
Standalone Grading
Use rule-based, LLM-based, and combined grading on saved responses.
