Getting Started -- the DueCare Workbench in 3 minutes

A safety harness around Gemma 4 for migrant-worker recruitment and trafficking. Pick a model, flip safety layers, send a prompt, then grade the response. Everything runs locally in the Kaggle kernel; the public hub only receives content you anonymize and explicitly submit.

The flow

1

Pick a model

Gemma 4 E2B for speed, E4B for the baseline, 31B for depth. Multi-GB load -- expect 30-90 s.

2

Flip safety layers

Each layer toggles independently. Start with all off to see stock Gemma, then turn them on one at a time.

3

Send a prompt

Free-form on Chat, A/B on Harness Comparison, or batch from a ZIP on Process Files.

4

Grade the response

Deterministic rules, Gemma-as-judge, or combined mode across 46 dimensions.

The six layers

Persona

Anti-trafficking expert system instructions. Keeps Gemma in the right register.

GREP

161 deterministic regex rules covering debt bondage, document retention, fee camouflage, ILO indicators.

RAG

Retrieval over a 46-document public legal/NGO corpus with a 46-edge citation graph.

Imports

User-provided local evidence kept in-session. Files never leave the kernel unless you anonymize + submit.

Tools

Gemma 4 native function calls: corridor fee caps, ILO indicators, NGO intake contacts.

Online

Optional web search treated as candidate evidence, not ground truth. Off by default.

Other workflows

Process Files -- drop a folder of case notes, scans, or chat exports. Builds a local knowledge graph you can chat against.

Knowledge Extraction -- paste a passage; Gemma 4 drafts a standardized KnowledgeObject (rule / citation / indicator).

Anonymization & Sharing -- review extracted facts, redact, and submit to the public hub at gemma4-comp.onrender.com (moving to duecare-ai.com).

Sync -- pull vetted (and optionally unvetted) knowledge from the hub into this kernel.

Trust boundary

Everything you upload or paste stays in /kaggle/working/ inside the kernel. The only outbound traffic is Sync (a GET for already-public packs) and Submit on Anonymization & Sharing (an explicit POST you trigger, with an audit log).
