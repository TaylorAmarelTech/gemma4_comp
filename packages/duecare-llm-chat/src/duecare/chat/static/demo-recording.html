Recording Checklist

A short operator page for the final Kaggle video. Use this to open each lane in a stable order, preload the platform moderation prompt with its synthetic image, and download JSON replay artifacts after each run.

Health checks query local kernel endpoints only (/api/version, /api/model-info, /api/audit/workbench-inventory, etc.). No user data is sent off-device. External links (Live Demo, Evaluation) open corresponding Kaggle notebooks in a new tab and are read-only navigation targets. Sample artifact downloads are synthetic composite data only — no real case files or PII.

Before Recording

  • Restart the Kaggle kernel after pulling the latest wheel/data version. Confirm the top strip shows the expected DueCare version.
  • Open the model selector and load Gemma 4 E4B-it for speed, or Gemma 4 31B-it only if there is time for slower first responses.
  • Use Enable local on Chat for Persona, GREP, RAG, Import, and Tools. Leave Official Sources and Online off unless you want live network behavior on camera.
  • For Bulk File Review, say that OCR/media and optional Gemma edge generation are explicit follow-up actions. The deterministic graph path is the fast recording path.
  • After each lane, click Replay JSON in the top bar so the demo has a reconstructable browser-side API trace.

What To Say Clearly

SurfaceRecording-safe framing
Chat moderationGemma 4 is grounded by deterministic indicators, retrieved legal sources, corridor tools, and an auditable trace. The synthetic image is bundled only to demonstrate multimodal evidence attachment.
Bulk File ReviewFast path is deterministic extraction, entity linking, typed graph edges, and optional Gemma case brief. OCR/media vision is shown as a queue/follow-up unless a compatible OCR or multimodal model is wired in the live run.
Knowledge ExtractionDrafting produces reviewable envelopes. Promotion is human-approved; importing changes local harness behavior without exposing raw source text.
SearchSearch is secondary and gated by query sanitization. Public-source results can become draft knowledge only after review.
Anonymization & SharingThe hub receives sanitized proposals and signals, not raw worker case files. Automatic labels cannot silently upgrade anonymous content into attributed content.

The cached platform trace is a recording aid, not a replacement for the live run. If the model is slow, show the bundled trace JSON and the browser Replay JSON so the call can be recreated after the video.
