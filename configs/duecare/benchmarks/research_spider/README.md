# Public Research Spider Seed Pack

Purpose: deterministic seed artifacts for expanding DueCare benchmark coverage
from public sources without ingesting private case files.

Generated by:

- `scripts/public_research_spider.py` for public-source query/source/prompt
  seed artifacts.
- `scripts/public_tool_survey.py` for search/crawl/extraction tool evaluation
  and frontier resume artifacts.
- `scripts/public_search_providers.py` for deterministic manual fallbacks and
  optional fakeable Brave/GitHub search-provider wrappers.
- `scripts/public_fetch_extract.py` for no-network fixture extraction and
  optional public HTML/PDF/document extractor wrappers after fetch gates.
- `scripts/public_source_manifest.py` for robots/manual-review fetch queues
  and per-domain sitemap-first frontiers.
- `scripts/public_sitemap_frontier.py` for advertools-compatible sitemap probe
  queues, domain crawl policies, and sitemap discovery dorks without fetching.
- `scripts/public_branching_research_queue.py` for a ranked 1,000-lead
  review backlog spanning source profiles, dorks, sitemap leads, and coverage
  gaps.
- `scripts/public_benchmark_expander.py` for coverage summaries,
  corroboration links, verified-for-benchmark knowledge rows, source
  decompositions, multi-turn conversations, hybrid scenarios, long-context
  prompts, refusal/detection prompts, applicability seeds, and deferred
  branches.
- `scripts/public_archive_manifest.py` for manifest-only WARC/cache/replay
  planning without committing raw response bodies.

Artifacts:

- `search_queries.jsonl`: aggressive official-source query expansion across
  IOM, Philippine government, Hong Kong government, China government/court,
  US justice/DHS/State, UK Home Office/CPS/NCA, Canada public safety/justice,
  Australia Home Affairs/AGD/AFP, New Zealand immigration/employment/police,
  Singapore MOM/police, EU/Interpol law-enforcement, supply-chain due
  diligence, intergovernmental, and public case-law sources.
- `deep_search_dorks.jsonl`: Google-style dorks for PDF/non-HTML artifacts,
  URL/title operators, recent reports, case/prosecution language, indicator
  guidance, sector/corridor combinations, and noise-filtered broad searches.
- `manual_search_fallbacks.jsonl`: browser-ready fallback URLs for search
  providers when API keys, quotas, or network access fail.
- `source_candidates.jsonl`: scored public-source candidates using URL,
  title, snippet, source family, source tier, jurisdictions, and redaction
  counts.
- `source_profiles.jsonl`: per-source extracted terms, signals, and
  recommended follow-up terms.
- `source_fetch_manifest.jsonl`: per-source fetch/extract queue with content
  kind, extractor plan, robots/manual-review requirements, and privacy flags.
- `source_domain_frontier.jsonl`: domain-level crawl frontier with robots URL,
  sitemap candidates, signal coverage, and polite queue policy.
- `source_manifest_summary.json`: source-fetch manifest counts and content
  kind breakdown.
- `source_archive_manifest.jsonl`: manifest-only WARC/cache capture plan for
  each queued public source.
- `source_replay_manifest.json`: replay ordering, archive boundaries, and
  metadata-only fallback policy.
- `source_archive_summary.json`: archive/replay counts and privacy boundary.
- `sitemap_probe_queue.jsonl`: robots and sitemap probe queue for public
  domains, with advertools optional and network disabled by default.
- `domain_crawl_policy.jsonl`: per-domain allow/deny hints, crawl order,
  extractor plans, and no-evasion/no-proxy policy.
- `sitemap_discovery_dorks.jsonl`: domain-scoped sitemap/report dorks for
  manual or API search expansion.
- `sitemap_frontier_summary.json`: sitemap queue counts and privacy boundary.
- `branching_research_queue.jsonl`: ranked public-source leads with requested
  work products for facts, dimensions, tests, prompts, conversations, and
  verification gaps.
- `branching_research_summary.json`: queue counts by lead type, signal, and
  source family.
- `source_profile_coverage.json`: signal, source-family, jurisdiction, and
  sector coverage against the target research frontier.
- `corroboration_links.jsonl`: cross-source signal-overlap links for
  benchmark-seed corroboration.
- `verified_knowledge_objects.jsonl`: knowledge rows verified only for
  benchmark seed use unless source content/date checks are later recorded.
- `source_decompositions.jsonl`: per-source decomposition cards that turn
  public metadata into reviewable behavior hypotheses, camouflage patterns,
  indicator trails, next-search terms, and prompt/test branches.
- `decomposition_followup_queries.jsonl`: source-decomposition-derived search
  dorks that branch each article/case/report into same-domain and cross-domain
  public follow-up leads.
- `decomposition_mixed_conversations.jsonl`: longer hybrid conversations that
  combine public source metadata, aggregate private pattern IDs, benign
  distractors, unsafe record-alteration requests, and expected safe responses.
- `conversation_prompts.jsonl`: synthetic multi-turn benchmark conversations.
- `conversation_manifest.json`: conversation, hybrid, long-context,
  refusal/detection, and applicability coverage counts.
- `hybrid_scenario_prompts.jsonl`: synthetic mixed scenarios combining public
  source signals with aggregate private pattern IDs.
- `long_context_stress_prompts.jsonl`: synthetic long-context benchmark
  packets with middle-needle indicators, benign distractors, sparse metadata,
  and aggregate private pattern IDs only.
- `refusal_detection_prompts.jsonl`: synthetic dual-purpose safety prompts
  that require detecting likely exploitation dimensions and refusing
  concealment, coaching, record alteration, or evasion requests.
- `applicability_seed_tags.jsonl`: seeds where prompt content should add
  applicability groups beyond sparse rule tags.
- `rejected_sources.jsonl`: rejected or deferred source branches and retry
  strategies.
- `second_wave_queries.jsonl`: per-source follow-up dorks generated from each
  candidate's title, snippet, URL path, source family, and detected signals.
- `knowledge_objects.jsonl`: candidate knowledge/context objects distilled
  from public metadata and signal templates. These are not confirmed facts
  until source dates, source types, and corroboration are verified.
- `dimension_candidates.jsonl`: candidate rubric dimensions derived from
  recurring public-source behavior patterns.
- `prompt_candidates.jsonl`: synthetic prompt candidates derived from public
  source metadata only.
- `test_candidates.jsonl`: regression-test ideas for crawler safety,
  fallback, deduplication, scoring, and privacy behavior.
- `fallback_playbook.json`: provider, robots.txt, parsing, privacy, and
  manual-review fallbacks.
- `tool_evaluation_matrix.jsonl`: deterministic evaluation of search APIs,
  crawlers, browser automation, extractors, archive tooling, and OSINT-adjacent
  tools before any dependency is adopted.
- `tool_adoption_notes.md`: human-readable adoption, deferral, and rejection
  notes for the tool survey.
- `search_provider_registry.json`: search-provider candidates and safe fallback
  status.
- `crawler_provider_registry.json`: crawler/spider candidates and safe fallback
  status.
- `extractor_provider_registry.json`: extractor/archive candidates and safe
  fallback status.
- `tool_survey_summary.json`: tool-survey counts and privacy summary.
- `research_frontier.json`: queued branches for the next autonomous research
  loops.
- `research_run_state.json`: resumable state for the current frontier run.
- `frontier_handoff.md`: concise continuation handoff with the next 30
  branches.
- `summary.json`: counts and privacy metadata.

Privacy rules:

- Do not feed raw private case files or worker chats into this spider.
- Public URLs and public source titles are allowed.
- Search snippets are redacted for email, phone-like, passport-like, and
  SSN-like strings before artifacts are written.
- Prompt candidates use public URL metadata only and must keep people,
  organizations, and case facts abstract or placeholder-based.
- Knowledge objects are context drafts, not production facts; keep them in
  `candidate_needs_human_or_model_verification` state until independently
  checked against public sources.
- Robots-disallowed pages remain metadata-only candidates; they are not fetched.
