# Archived Kaggle notebook previews — 2026-05-11

This folder holds `.ipynb` notebook wrappers, generated/research kernel metadata, legacy notebook mirrors, and skunkworks notebook experiments moved out of the active submission tree on 2026-05-11.

The active judge-facing workflow is kernel-first:

1. Edit `kaggle/*/kernel.py` and the folder `README.md`.
2. Copy the full `kernel.py` into Kaggle manually.
3. Attach the matching wheel dataset and model sources.
4. Run from the Kaggle UI.

These archived notebooks are historical preview wrappers only. Do not edit or republish from this archive unless Taylor explicitly asks for historical recovery.

Preserved paths mirror their original locations so a file can be traced back if needed:

- `kaggle/*/notebook.ipynb` — root submission preview wrappers.
- `kaggle/kernels/*/` — generated/research notebook mirrors plus metadata.
- `legacy_notebooks/` — old root-level notebook mirrors.
- `skunkworks/notebooks/` — exploratory jailbreak/proof-of-concept notebooks.
