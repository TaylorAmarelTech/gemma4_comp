## 1. The single most important new capability: tests run locally again

The system Python under this OneDrive-synced repo is corrupted **down to the
standard library** (sync strips files: `typing_extensions`, the compiled
`pydantic_core._pydantic_core.pyd`, `pydantic.main`, `html.entities`). For a
while this made `pytest` unrunnable locally, so the full suite went unverified.

That is now fixed. **Run the suite with:**

```powershell
pwsh scripts/recover_test_env.ps1 -Run        # grading/harness subset (GREEN baseline)
pwsh scripts/recover_test_env.ps1 -Full       # the entire suite (packages + tests)
pwsh scripts/recover_test_env.ps1 -Regenerate -Full   # rebuild env from scratch + full run
```

It builds a clean uv-managed CPython venv **outside OneDrive** (in
`%LOCALAPPDATA%\gemma4-testenv`) with the known-working pins in
`requirements-testenv.txt`. Full write-up: [`docs/local_test_env.md`](local_test_env.md).
Do **not** try to run pytest on the system Python — it cannot import the app.
